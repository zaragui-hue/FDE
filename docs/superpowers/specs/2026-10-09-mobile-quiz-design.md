# FDE 题库手机刷题页面设计

日期：2026-10-09

## 目标

把现有 Excel 题库做成手机上容易阅读和练习的网页。访问者打开网址即可使用，无登录、用户名或服务器账户。“看解答”和“刷题”是两个随时可切换的模式；学习进度只保存在当前设备的当前浏览器中。网页计划发布到免费的 GitHub Pages。

## 题库内容

- 以 `人工智能应用FDE工程师测试题目 260827.xlsx` 为内容主源，导入 80 道单选、40 道多选、80 道判断和 10 道简答。逐题核对其他三个工作簿后，把「工信人才实名系统」中 1 道问法不同、选项和答案相同的多选题单独纳入，共 211 道，题型数量为 80／41／80／10。其余相同题目不重复导入。
- 客观题保留题干、选项、标准答案、解析和原有章节来源。简答题保留题面、问题项、参考答案及评分标准、章节来源。
- 导入时统一多选答案的分隔符及判断题的答案写法，并检查答案对应的选项。每道题分配固定 ID，使后续页面更新时已有进度仍能对应原题。
- 原始章节标签写法不统一。首版按题型筛选，章节来源显示在题目下方作为参考。

## 页面与操作

### 首页

打开网址直接显示首页。首屏放“看解答”和“开始刷题”两个主要入口，并显示本机已看题数、已作答题数及待复习错题数。“继续”回到各模式上次停留的位置。手机界面采用单列布局，长题干和长选项自动换行，不横向滚动。

### 看解答

可以选择全部题或单选、多选、判断、简答中的一种。每次展示一题，题目下方直接显示标准答案与解析；简答题显示参考答案及评分标准。上一题、下一题和题目列表都能导航。打开某题即记为“已看”，并保存当前阅读位置。用户可随时切到刷题模式，不需要读完全部题。

### 刷题

可选全部题或指定题型，按顺序或随机练习。随机练习在本轮题目用完前不重复，并保存本轮顺序和当前位置。每次展示一题，提交前隐藏答案和解析。单选、判断点选一项；多选可选多项，提交后按完整选项集合判定。提交后显示对错、正确答案及原表解析。“已作答题数”按不同题目计数；未提交而跳过的题不计入。

简答题提供输入区，也允许只在心里作答。点击“查看参考答案”后展示评分标准，再由用户选择“会／模糊／不会”；不对自由文本自动评分。“模糊”和“不会”的简答题进入待复习列表。

### 错题复习

答错的客观题和标为“模糊”或“不会”的简答题进入待复习列表。用户可以从列表重新作答。客观题重做正确、简答题改标为“会”后，从待复习列表移除。列表按题目去重，保留当前复习状态。

## 本地保存与备份

- 同一个浏览器只维护一份进度，保存已看题目、两种模式的当前位置、随机练习的本轮顺序、各题最近一次作答结果和待复习状态。关闭并重新打开浏览器后继续使用。
- 手机、电脑和不同浏览器的记录彼此独立，即使打开同一网址也不会自动同步。
- 设置页提供“导出进度”和“导入进度”。导出为 JSON 文件；导入前检查文件格式和题库版本，显示将覆盖本机记录的提示，用户确认后才替换。这样可以手动备份或迁移设备。
- 浏览器若阻止本地保存，页面仍可看题、做题，但要明确提示本次进度不能保存。清理网站数据可能删除本机记录，因此备份入口保持容易找到。

## 发布与数据流

题库在制作阶段从 Excel 转成网页读取的数据文件，网页文件与题库数据通过 GitHub Pages 发布。题目和答案会对访问网页的人公开。浏览器从网站加载题库，所有进度读写仅发生在本地；没有后台服务，也不上传答题记录。

## 完成标准

1. 页面正确展示 211 道不同问法，四种题型数量分别为 80／41／80／10；客观题答案与对应工作簿一致。
2. 手机上能完整阅读长题干、长选项和简答参考答案，并顺利切换两种模式。
3. 刷新或重新打开页面后，已看、作答、当前位置和错题状态仍在。
4. 导出的进度可在另一浏览器导入；无效或不兼容文件不会覆盖现有进度。
5. GitHub Pages 发布后，手机和电脑能通过网址打开页面并完成上述操作。
